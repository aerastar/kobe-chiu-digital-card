# Kobe Chiu Digital Card

GitHub Pages-ready static site.

## Files
- `index.html` — the digital card webpage
- `kobe-chiu-card.png` — card image
- `Kobe_Chiu_Contact.vcf` — downloadable contact card

## Publish with GitHub Pages
1. Create a new public GitHub repository named `kobe-chiu-digital-card`.
2. Upload all files from this folder to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select **main** and **/(root)**, then save.
6. After GitHub finishes publishing, the URL will look like:
   `https://YOUR-USERNAME.github.io/kobe-chiu-digital-card/`

If this is published under the `aerastar` GitHub account, the expected URL is:
`https://aerastar.github.io/kobe-chiu-digital-card/`
